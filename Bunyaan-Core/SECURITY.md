# Security Policy

Use the latest published source revision. Report vulnerabilities privately to the project maintainers through the private contact channel listed by the repository owner; do not publish exploit details before a fix is available. Include affected version, reproduction steps and impact. Do not upload secrets or private user data.

Treat model checkpoints, uploaded GLB files, image textures and dataset manifests as untrusted input. Validate file size and format, keep dependencies patched, and only load checkpoints from trusted sources.
