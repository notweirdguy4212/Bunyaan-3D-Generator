# Bunyaan — Независимая генеративная 3D-модель

**Bunyaan — открытый исследовательский проект для генерации 3D и PBR-материалов. Архитектура, обусловливание, диффузия, обучение, инференс и форматы контрольных точек реализованы в самом Bunyaan. Другие генеративные модели не встраиваются и не требуются.**

> **Репозиторий содержит обучаемые собственные архитектуры и воспроизводимые инструменты, но не содержит предварительно обученных весов. Качество зависит от данных, вычислительных ресурсов и оценки.**

## النطاق / Scope

3D-путь использует текстовое/визуальное обусловливание и диффузию поля занятости. Материальный путь генерирует пять UV-каналов: RGB, шероховатость и металличность.

## بيانات التدريب والحقوق

Используйте только ресурсы, лицензия которых явно разрешает обучение ML. Сохраняйте хэши, происхождение, атрибуцию и лицензию. Неизвестная лицензия не означает разрешение.

## البدء / Quick start

Полное руководство находится в `README.md`. Установите Python 3.10–3.12, совместимый PyTorch и выполните `pip install -r requirements.txt`. Для команд обучения и оценки используйте `--help`.

## الترخيص

Код и документация Bunyaan распространяются по Apache-2.0. Датасеты и зависимости сохраняют собственные лицензии.

اقرأ ملف [`README.md`](README.md) الإنجليزي للحصول على تفاصيل البنية، والقيود، وخطوات التقييم، وخريطة الطريق، والمساهمة، والأمان.


## Bunyaan v1.5 engineering update

The native v1.5 research path adds a hierarchical 3D feature encoder, arbitrary-coordinate implicit SDF/PBR decoder, chunked field queries, calibrated multi-view fusion, and SDF/normal/PBR/Eikonal training. This is not pretrained and has not been shown to outperform TRELLIS.2. See `docs/ARCHITECTURE-v1.5.md`, `UPGRADE-NOTES-v1.5.md`, and `training/train_implicit.py`.
