# TexVerse integration notice

This folder contains TexVerse model-ID indexes, not the actual 3D assets or UV texture images.
The upstream dataset reports 858,669 models and 158,518 PBR-material models. Assets and
full metadata are hosted separately by the dataset maintainers. Do not interpret an ID as
a downloaded asset or a training example.

Individual asset licenses vary. Bunyaan's preparation tooling defaults to a conservative
allowlist (`CC0`, `CC BY`, `CC BY-SA`) and records provenance. Non-commercial and
no-derivatives licenses are excluded by default. Verify each asset's current license and
the terms governing machine-learning training before use or redistribution.

Upstream project: https://github.com/Yibo-Zhang/TexVerse (see the supplied upstream README
for authoritative dataset download locations and citation).
