# Contributing to Bunyaan

1. Open an issue describing the problem or proposal before large changes.
2. Work on a focused branch and keep changes reviewable.
3. Add or update tests for behavior changes; run `pytest -q` from `Bunyaan-Core`.
4. Document tensor shapes, channel order, units, coordinate conventions and checkpoint compatibility.
5. Include provenance and license evidence for every contributed sample asset. Do not submit assets with unknown ML-training rights.
6. Never commit secrets, private datasets, model weights you cannot redistribute, or generated binaries unnecessarily.
7. By submitting a contribution, you agree it is offered under the repository's Apache-2.0 license unless explicitly agreed otherwise.

Please be respectful, specific and constructive in code review.
