# Bunyaan — Незалежна генеративна 3D-модель

**Bunyaan — це відкритий дослідницький проєкт для генерації 3D та PBR-матеріалів. Архітектура, кондиціювання, дифузія, навчання, інференс і формати контрольних точок є власними компонентами Bunyaan. Інші генеративні моделі не вбудовуються й не потрібні.**

> **Репозиторій містить власні архітектури для навчання та відтворювані інструменти, але не містить попередньо навчених ваг. Якість залежить від даних, обчислень та оцінювання.**

## النطاق / Scope

3D-шлях використовує текстове/візуальне кондиціювання та дифузію поля зайнятості. Шлях матеріалів генерує п’ять UV-каналів: RGB, шорсткість і металічність.

## بيانات التدريب والحقوق

Використовуйте лише ресурси, ліцензія яких прямо дозволяє ML-навчання. Зберігайте хеші, походження, атрибуцію та ліцензію. Невідома ліцензія не є дозволом.

## البدء / Quick start

Повний посібник див. у `README.md`. Встановіть Python 3.10–3.12, сумісний PyTorch і виконайте `pip install -r requirements.txt`. Для команд навчання й оцінювання використовуйте `--help`.

## الترخيص

Код і документація Bunyaan поширюються за Apache-2.0. Набори даних і залежності зберігають власні ліцензії.

اقرأ ملف [`README.md`](README.md) الإنجليزي للحصول على تفاصيل البنية، والقيود، وخطوات التقييم، وخريطة الطريق، والمساهمة، والأمان.


## Bunyaan v1.5 engineering update

The native v1.5 research path adds a hierarchical 3D feature encoder, arbitrary-coordinate implicit SDF/PBR decoder, chunked field queries, calibrated multi-view fusion, and SDF/normal/PBR/Eikonal training. This is not pretrained and has not been shown to outperform TRELLIS.2. See `docs/ARCHITECTURE-v1.5.md`, `UPGRADE-NOTES-v1.5.md`, and `training/train_implicit.py`.
