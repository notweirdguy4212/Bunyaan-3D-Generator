# Bunyaan v1.3 — Standalone open-source edition

- Bunyaan is distributed as an independent native model project.
- Bundled external model repositories have been removed from this release archive.
- Project license is Apache-2.0; see `LICENSE`.
- Added a professional model card, contribution/security guidance, citation metadata and scalable SVG diagrams.
- Added README editions in 15 languages (English master plus 14 translations).
- Existing native 3D and five-channel material model implementations remain research prototypes; no pretrained weights are included.
- TexVerse-compatible ingestion and training tools remain available. Source assets must be separately obtained and rights-cleared.
